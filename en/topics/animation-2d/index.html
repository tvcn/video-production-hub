2D animation

Judgement：Key drawings, lip sync, cycles and timing: the space between two drawings decides the weight of a move.

20 guides · ordered by problem, not publish date

Read these five first

  1. Start: frame it2D Animation: Keyframes, Breakdowns, Loops

    2D is not about beautiful drawings. It is about controlling time with keys and breakdowns. Make one action read first.

  2. Next: choose the moveStop Motion: One Frame at a Time

    Stop motion is a test of stability: lock the camera, lock the light, move the puppet a little each frame. Two seconds in a day is normal. You are not slow.

    Walks look hard because feet slide, weight is wrong, and limbs move together. Lock the four poses first, then talk style.

  6. Animation / Lip sync

    Lip Sync: Close on Consonants, Open on Vowels

    Lip sync is not a drawing for every word. Land the closed consonants, open on the vowels, let the expression arrive late, and the audience believes the voice.

  7. Animation / Principles

    The Twelve Principles: Use One at a Time

    The twelve principles are not filters. Use one to explain one action; otherwise the audience sees noise.

  8. Animation / 3D

    Rigging: Make the Joints Turn

    Rigging makes joints turn correctly before skin looks good; if the joint fails, weights cannot save it.

  9. Animation / Motion graphics

    Motion Typography: Read, Then Move

    Type must read at rest before it moves; reading while moving cuts comprehension in half.

  10. Animation / Principles

    Weight: The Acceleration on Landing

    Weight is not a pose; it is acceleration in the landing frames. Without it, everything floats.

  11. Animation / Principles

    Anticipation: Show the Next Move

    Anticipation tells the audience what is coming; without it, action feels pasted in.

  12. Animation / 2D

    Run Cycle: Feet and Center of Gravity

    Set the center of gravity and footfall order before arms; wrong feet make the whole body float.

  13. Animation / 2D

    Loop Cycle: Match the First and Last Frame

    The first and last frames must match, or the loop twitches every cycle.

  14. Animation / 2D

    2D Compositing: Separate Background, Character, Light

    Separate background, character, and light. Flattened layers force a full redraw for one change.

  15. Animation / 2D

    2D Camera: Pan and Multiplane

    A 2D camera is not one big pan; multiple layers at different speeds create space.

  16. Animation / 3D

    Blockout: Proportions and Camera First

    Blockout sets scale, camera, and timing before detail. Get it wrong and everything is redone.

  17. Animation / 3D

    Modeling: Silhouette Before Polygons

    Read the silhouette before polygon count. A wrong outline stays wrong at any density.

  18. Animation / 3D

    Materials: Roughness and Specular

    Roughness and specular decide plastic, wood, or metal before texture maps.

  19. Animation / 3D

    3D Lighting: Three Points and HDRI

    Use key, fill, and rim to build structure, then HDRI for environment. Reverse the order and space flattens.

  20. Animation / 3D

    Render: Samples and Noise

    Samples and noise come before resolution; unresolved noise at 4K is just bigger dirt.
