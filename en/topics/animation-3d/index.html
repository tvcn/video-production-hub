TOPIC / animation

3D and pipeline

Rigging, materials, rendering, compositing and pipeline: lock assets before shots, budget time before quality.

13 guides · grouped by topic, not publish date

  1. Animation / 3D

    The 3D Pipeline: Blockout to Render

    3D does not start with animation after modeling. Blockout sets timing, then layout, animation, lighting, and render, each step reversible.

  2. Animation / 3D

    Rigging: Make the Joints Turn

    Rigging makes joints turn correctly before skin looks good; if the joint fails, weights cannot save it.

  3. Animation / 2D

    2D Compositing: Separate Background, Character, Light

    Separate background, character, and light. Flattened layers force a full redraw for one change.

  4. Animation / 3D

    Blockout: Proportions and Camera First

    Blockout sets scale, camera, and timing before detail. Get it wrong and everything is redone.

  5. Animation / 3D

    Modeling: Silhouette Before Polygons

    Read the silhouette before polygon count. A wrong outline stays wrong at any density.

  6. Animation / 3D

    Materials: Roughness and Specular

    Roughness and specular decide plastic, wood, or metal before texture maps.

  7. Animation / 3D

    3D Lighting: Three Points and HDRI

    Use key, fill, and rim to build structure, then HDRI for environment. Reverse the order and space flattens.

  8. Animation / 3D

    Render: Samples and Noise

    Samples and noise come before resolution; unresolved noise at 4K is just bigger dirt.

  9. Animation / 3D

    Layout: Camera and Asset Handoff

    Layout locks camera, scale, and asset versions before animation. A vague handoff makes animators guess.

  10. Animation / Stop motion

    Stop-Motion Motion Blur: Shoot It Twice

    Stop-motion blur comes from double exposure or post compositing, not a lower frame rate.

  11. Animation / Pipeline

    Animatic Pipeline: Voice, Timing, Board

    Lay temp voice, set duration, then revise the board. Without sound, timing is fiction.

  12. Animation / Pipeline

    Asset Handoff: Names, Versions, Cache

    Handoff states names, versions, cache, and dependencies. Miss one and the next person rebuilds.

  13. Animation / Case

    Animation Case: From Board to Final

    Review the case through board, animatic, layout, animation, lighting, and comp, not just the final.
