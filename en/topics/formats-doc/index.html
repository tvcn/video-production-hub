TOPIC / formats

Documentary and events

Judgement：Documentary, interview, event and wedding: protect the scene before styling it; make the person real before making the process look good.

20 guides · ordered by problem, not publish date

Read these five first

  1. Start: frame itDocumentary Short: Capture a Change

    Find one person, then wait for one thing to happen. The film usually works because something changed between the first day and the last.

  2. Next: choose the moveWedding Film Structure: Ceremony Before Style

    Protect ceremony and vows before slow motion and grading; style cannot save a missed ritual.

  3. Then: failure modesDocumentary Breakdown: One Person, One Event, One Change

    An eight-beat breakdown of a three-minute documentary: action, person, want, obstacle, attempt, cost, change, after.

  4. Check: prove itDocumentary Template: One Person, One Thing, One Change

    One person, one concrete task, one visible change. Do not start with an era.

  5. Cross-read: one moreNews Structure: Scene First, Verification Second

    Scene first, verification second. Background first loses the viewer.
