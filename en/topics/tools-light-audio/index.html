TOPIC / tools

Light and sound gear

LEDs, diffusion, wireless mics and recorders: solve direction and distance before power and brand.

20 guides · grouped by topic, not publish date

  1. Tools / Audio

    Audio Basics: Mic Position Beats Price

    A cheap mic twenty centimeters from the mouth usually beats an expensive rig mounted on the camera.

  2. Tools / Capability card

    LED Panel: CRI and Brightness

    Check CRI and real output, not wattage on the box; green skin means the color is wrong.

  3. Tools / Capability card

    COB Light: One Source, One Soft Box

    A COB is a bare source; pair it with a soft box or lantern or the face gets hard shadows.

  4. Tools / Capability card

    Softbox: Size Decides Softness

    Bigger and closer means softer; move the box before changing the light.

  5. Tools / Capability card

    Lighting Gel: CTO, CTB, ND

    Know CTO, CTB, and ND: warm, cool, and dim. The wrong gel changes the whole set.

  6. Tools / Capability card

    Practical Bulb: Color Temperature and Dimming

    A practical must dim and shift color temperature, or it is only a prop, not a source.

  7. Tools / Capability card

    Light Stand: Sandbag Everything

    Sandbag the stand before raising the light; an unweighted stand costs more than the lamp when it falls.

  8. Tools / Capability card

    Wireless Lav: Frequency and Backup

    Check frequency and interference, and record a backup track; the set gives no second chance.

  9. Tools / Capability card

    Field Recorder: 32-Bit Is Not Magic

    32-bit float can rescue clipping, not dialogue eaten by wind; mic and placement still come first.

  10. Tools / Capability card

    Timecode: Sync Without Guessing

    Timecode syncs cameras and recorders in the first minute of post; without it, sync is luck.

  11. Tools / Capability card

    Audio Interface: Inputs and Gain

    Check input count, gain range, and noise floor; a expensive interface with low gain cannot record a whisper.

  12. Tools / Capability card

    Wireless Video: Latency and Interference

    Test latency and interference before sending to director or focus puller; a dropped signal stops the set.

  13. Tools / Capability card

    AI Audio Tool: Rights and Quality

    Check rights and audio quality before features; a cloned voice's license matters more than timbre.

  14. Tools / Tutorial

    One-Light Portrait: Direction First

    Set direction first: 45 degrees, side, or backlight; then softness and intensity.

  15. Tools / Tutorial

    Night Practical: Balance the Lamp

    Make the lamp in frame believable, then add a small face light; a big ratio looks fake.

  16. Tools / Buying guide

    Buy Audio First: Mic, Noise Floor, and Gain

    Audiences forgive a plain image; they do not forgive unclear sound. On a limited budget, put money into a microphone and recorder before a second lens.

  17. Tools / Buying guide

    Buying a Light Kit: Soft Before Bright

    The first light kit is not the brightest; it is the easiest to control skin and shadow. Soft area, consistent color, and dimmability matter more than peak output.

  18. Tools / Buying & fixes

    Renting Lighting: List and Damage

    List, test, and photograph the gear; one missing soft box costs an hour on set.

  19. Tools / Buying & fixes

    Audio Noise Fix: Start With the Room

    Start with the room: air conditioning, lights, outlet, cable; blame the mic last.

  20. Tools / Buying guide

    Field Recorder: Channels, 32-bit Float, and Timecode

    A field recorder is not about track count. It is about whether one lost channel has a backup, a wrong gain can be saved, and post can sync to timecode.
