Storage and backup

Judgement：Cards, drives, NAS and 3-2-1: calculate capacity and runtime before speed; make recovery possible before making it cheap.

20 guides · ordered by problem, not publish date

Read these five first

  1. Start: frame itMedia Management: Back Up Today, Name for Finding

    Back up before wrap. Put date, scene, and camera in the filename. Footage you cannot find was never shot.

  2. Next: choose the moveStorage Calculator: How Long Can You Roll?

    A prime forces you to step in, back, and change position; that is often better than turning a zoom ring.

  6. Tools / Capability card

    Zoom Lens: Convenience Has a Cost

    A zoom saves time but charges you in weight, aperture, and image; ask which one you can afford today.

  7. Tools / Capability card

    Anamorphic: Wide Screen, Not a Crop

    Anamorphic is not a top-and-bottom crop; it squeezes the image horizontally and restores it, giving oval bokeh and specific distortion.

  8. Tools / Capability card

    Speed Booster: Wider Angle, Faster Aperture

    A speed booster squeezes a full-frame lens onto a smaller sensor: wider view, about one stop faster, softer edges.

  9. Tools / Capability card

    Matte Box: Filters and Stray Light

    A matte box cuts stray light before holding filters; a cheap one can leak and ruin the frame.

  10. Tools / Capability card

    Follow Focus: One Hand Can Follow

    A follow focus gives marks and feel; autofocus is not reliable in darkness or fast motion.

  11. Tools / Capability card

    LED Panel: CRI and Brightness

    Check CRI and real output, not wattage on the box; green skin means the color is wrong.

  12. Tools / Capability card

    COB Light: One Source, One Soft Box

    A COB is a bare source; pair it with a soft box or lantern or the face gets hard shadows.

  13. Tools / Capability card

    Softbox: Size Decides Softness

    Bigger and closer means softer; move the box before changing the light.

  14. Tools / Capability card

    Reflector: Five Surfaces, One Job

    The five surfaces are five fill strengths, not five styles; start white, not silver.

  15. Tools / Capability card

    Lighting Gel: CTO, CTB, ND

    Know CTO, CTB, and ND: warm, cool, and dim. The wrong gel changes the whole set.

  16. Tools / Capability card

    Practical Bulb: Color Temperature and Dimming

    A practical must dim and shift color temperature, or it is only a prop, not a source.

  17. Tools / Capability card

    Light Stand: Sandbag Everything

    Sandbag the stand before raising the light; an unweighted stand costs more than the lamp when it falls.

  18. Tools / Capability card

    Shotgun Mic: Point It, Get Close

    A shotgun is directional; distance gives you room, not dialogue. Get close before denoising.

  19. Tools / Capability card

    Wireless Lav: Frequency and Backup

    Check frequency and interference, and record a backup track; the set gives no second chance.

  20. Tools / Capability card

    Field Recorder: 32-Bit Is Not Magic

    32-bit float can rescue clipping, not dialogue eaten by wind; mic and placement still come first.
