二维动画

判断：原画、口型、循环与时间感：两张原画之间，决定动作的重量。

20 篇 · 按问题顺序，不按发布时间

先读这五篇

  1. 先读：定问题2D 动画：关键帧、Breakdown、循环

    2D 不是一张张画得漂亮，而是用关键帧和 breakdown 控制时间。先让一个动作读得懂。

  2. 再读：选动作定格动画：一张一张拍

    定格最磨人的地方是稳定：相机别动、光别动、动作每次只改一点。一天拍两秒很正常，别以为自己慢。

  3. 补读：看失败3D 动画管线：从 blockout 到渲染

    3D 不是建模完就动画。先 blockout 定时间，再 layout、animation、lighting、render，每一步都能回退。

  4. 验读：做验收动画的时间感：两张原画之间，决定重量

    一个球从桌上掉下来，画几张中间帧、每张隔多远，观众就能感觉到它是乒乓球还是铅球。

  5. 横读：补一课走路循环：脚落地那一下

    走路看起来难，是因为脚会滑、重心不对、手脚同拍。先把四个姿势站住，再谈风格。

为什么这样排：先判断问题，再选动作，接着补失败与验收，最后横向补一课；不是按发布时间，也不是按文章数量。下面 8 篇以上是完整子页清单。

  1. 动画 / 2D

    2D 动画：关键帧、Breakdown、循环

    2D 不是一张张画得漂亮，而是用关键帧和 breakdown 控制时间。先让一个动作读得懂。

  2. 动画 / 定格

    定格动画：一张一张拍

    定格最磨人的地方是稳定：相机别动、光别动、动作每次只改一点。一天拍两秒很正常，别以为自己慢。

  3. 动画 / 3D

    3D 动画管线：从 blockout 到渲染

    3D 不是建模完就动画。先 blockout 定时间，再 layout、animation、lighting、render，每一步都能回退。

  4. 动画 / 时间

    动画的时间感：两张原画之间，决定重量

    一个球从桌上掉下来，画几张中间帧、每张隔多远，观众就能感觉到它是乒乓球还是铅球。

  5. 动画 / 循环

    走路循环：脚落地那一下

    走路看起来难，是因为脚会滑、重心不对、手脚同拍。先把四个姿势站住，再谈风格。

  6. 动画 / 口型

    口型：先对辅音，再画表情

    口型不是把每个字都画出来。先对闭唇的辅音，再给元音开口，表情晚半拍，观众就觉得是他在说。

  7. 动画 / 原理

    十二原则：别一次全用

    十二原则不是十二个滤镜；一个动作先用一个原则解释，观众才看得懂。

  8. 动画 / 三维

    绑定：让关节能转

    绑定先让关节转得对，再让皮肤变形好看；转不动，权重再细也没用。

  9. 动画 / 动效

    字效：先读清再动

    字效先保证静止时读得清，再决定怎么动；边动边读，阅读速度会掉一半。

  10. 动画 / 原理

    重量：落地的加速度

    重量不在姿势，在落地那几帧的加减速；没有加速度，一切像气球。

  11. 动画 / 原理

    预备动作：让观众先知道

    预备动作让观众提前知道要发生什么；没有预备，动作像突然被剪进来。

  12. 动画 / 二维

    跑步循环：脚与重心

    跑步循环先定重心和脚掌着地顺序，再修手臂；脚不对，全身都飘。

  13. 动画 / 二维

    循环动作：首尾怎么接

    循环动作首尾帧必须对得上，否则每转一圈就抖一下。

  14. 动画 / 二维

    二维合成：背景、前景、光

    二维合成把背景、人物、光效分层；全压在一张图里，改一个动作就要重画全部。

  15. 动画 / 二维

    二维运镜：pan 与 multiplane

    二维运镜不是把整张图平移；用多层不同速度，才有空间。

  16. 动画 / 三维

    Blockout：先定比例和机位

    Blockout 先定比例、机位和时长，不建模细节；这一步错了，后面全返工。

  17. 动画 / 三维

    建模：面数与轮廓

    建模先看轮廓，再看面数；轮廓不对，细分再多也不像。

  18. 动画 / 三维

    材质：粗糙度与高光

    材质先调粗糙度和高光，再贴纹理；这两项决定它是塑料、木头还是金属。

  19. 动画 / 三维

    三维灯光：三点与 HDRI

    三维灯光先用主光、补光、轮廓光定结构，再用 HDRI 补环境；顺序反了，空间会平。

  20. 动画 / 三维

    渲染：采样与噪点

    渲染先看采样和噪点，再看分辨率；噪点没压住，4K 也只是更大的脏。
