主题 / animation

三维与管线

绑定、材质、渲染、合成与管线：先锁资产，再谈镜头；先算时间，再谈质量。

13 篇 · 按主题聚合，不按发布时间

  1. 动画 / 3D

    3D 动画管线：从 blockout 到渲染

    3D 不是建模完就动画。先 blockout 定时间，再 layout、animation、lighting、render，每一步都能回退。

  2. 动画 / 三维

    绑定：让关节能转

    绑定先让关节转得对，再让皮肤变形好看；转不动，权重再细也没用。

  3. 动画 / 二维

    二维合成：背景、前景、光

    二维合成把背景、人物、光效分层；全压在一张图里，改一个动作就要重画全部。

  4. 动画 / 三维

    Blockout：先定比例和机位

    Blockout 先定比例、机位和时长，不建模细节；这一步错了，后面全返工。

  5. 动画 / 三维

    建模：面数与轮廓

    建模先看轮廓，再看面数；轮廓不对，细分再多也不像。

  6. 动画 / 三维

    材质：粗糙度与高光

    材质先调粗糙度和高光，再贴纹理；这两项决定它是塑料、木头还是金属。

  7. 动画 / 三维

    三维灯光：三点与 HDRI

    三维灯光先用主光、补光、轮廓光定结构，再用 HDRI 补环境；顺序反了，空间会平。

  8. 动画 / 三维

    渲染：采样与噪点

    渲染先看采样和噪点，再看分辨率；噪点没压住，4K 也只是更大的脏。

  9. 动画 / 三维

    Layout：镜头与资产交接

    Layout 把机位、比例、资产版本锁死，再交给动画；交接不清，动画师只能猜。

  10. 动画 / 定格

    定格运动模糊：拍两遍

    定格运动模糊靠两次曝光或后期合成，不是把帧率调低。

  11. 动画 / 管线

    Animatic：配音、定时、改镜头

    Animatic 先放配音、定每条时长、再改分镜；没有声音，时间感是假的。

  12. 动画 / 管线

    资产交接：命名、版本、缓存

    资产交接写清命名、版本、缓存和依赖；少一样，下一个人就要重做。

  13. 动画 / 案例

    短片复盘：从分镜到成片

    动画案例复盘按“分镜—animatic—layout—动画—灯光—合成”逐段对照，不只夸成片。
