影像史

摄影、电影、动画与电视的技术史：今天的工具不是凭空来的，每个限制都留下过痕迹。

20 篇 · 按主题聚合，不按发布时间

  1. 影像史 / 摄影

    1839：摄影第一次变成可复制的图像

    达盖尔法公布后，图像第一次能稳定地留在金属板上，也被复制、传播和收藏。它改变了“看见”的权力。

  2. 影像史 / 电影

    1895：电影成为公共娱乐

    卢米埃尔兄弟把放映变成买票、坐下、一起看。电影从技术演示变成了一种公共时间。

  3. 影像史 / 动画

    动画史：从赛璐珞到 3D

    从纸、赛璐珞到多边形，工具换了几轮，动画师每天面对的仍是同一个问题：怎么让静止的东西看起来想动。

  4. 影像史 / 版权

    版权：先查五件事，再发布

    画面、音乐、字体、肖像、场地，五项分别授权。CC 与商用授权不是一回事。

  5. 影像史 / 摄影

    从银版到手机：摄影的五次转身

    1839 年要坐着不动几十秒，1888 年柯达把相机交给普通人，1975 年传感器把光变成文件，2007 年手机让拍照变成默认动作。

  6. 影像史 / 观看

    脸为什么越来越近：从影院到手机

    景别不是导演突然爱拍特写，是屏幕变了。影院银幕能装下一张脸，电视只给你一个客厅，手机只给你拇指宽。观众离画面越近，脸就得越大。

  7. 影像史与素养 / 影像史

    暗箱：图像先学会倒过来

    暗箱早就知道光会成像，真正的新东西是它把“看见”变成可以复制的证据。

  8. 影像史与素养 / 媒介素养

    平台规则：什么会被限流

    平台规则不是玄学；重复搬运、夸大承诺、诱导互动和敏感画面，是最常见的限流点。

  9. 影像史与素养 / 法律与伦理

    无障碍字幕：让听不见的人也跟上

    无障碍字幕要让听不见的人知道谁在说、发生了什么、语气是什么，不只写台词。

  10. 影像史与素养 / 影像史

    迈布里奇：马跑起来的那一秒

    迈布里奇用一排相机拆开马的运动，第一次让人看见肉眼来不及看的瞬间。

    爱迪生 Kinetoscope：一个人看的电影

    活动电影放映机把影像装进盒子，一次只给一个人看；电影还没成为公共空间。

    卢米埃尔：火车进站吓到观众
