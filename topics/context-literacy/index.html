媒介与伦理

媒介、伦理、法律与算法：看懂画面，也看懂画面背后的条件、权力与责任。

20 篇 · 按主题聚合，不按发布时间

  1. 素养 / 媒介

    媒介素养：一条视频的五个问题

    不要先问“真的假的”，先问：谁做的、剪掉了什么、放在什么语境、为什么现在推给我。

  2. 影像史 / 版权

    版权：先查五件事，再发布

    画面、音乐、字体、肖像、场地，五项分别授权。CC 与商用授权不是一回事。

  3. 影像史与素养 / 媒介素养

    平台规则：什么会被限流

    平台规则不是玄学；重复搬运、夸大承诺、诱导互动和敏感画面，是最常见的限流点。

  4. 影像史与素养 / 法律与伦理

    无障碍字幕：让听不见的人也跟上

    无障碍字幕要让听不见的人知道谁在说、发生了什么、语气是什么，不只写台词。

  5. 影像史与素养 / 媒介素养

    来源核查：这条视频最初是谁发的

    来源核查先找最初发布者，再找原始文件；转发十万次，也不等于真实。

  6. 影像史与素养 / 媒介素养

    剪辑操控：删掉哪一句改变了意思

    剪辑操控常常只删一句话：删掉前提，结论就变了。

  7. 影像史与素养 / 媒介素养

    算法推荐：为什么你总看到同一种

    算法推荐按停留和互动放大相似内容；你越停，它越认定你喜欢。

  8. 影像史与素养 / 媒介素养

    标题党：标题承诺了什么，正文给了什么

    标题党先承诺一个强结果，正文只给一个弱例子；判断方法是把标题和正文各写一句。

  9. 影像史与素养 / 媒介素养

    深伪识别：看脸之外看什么

    深伪识别别只看脸；看牙齿、耳朵、眨眼、背景文字和光影方向。

  10. 影像史与素养 / 媒介素养

    数据视频：图表有没有骗人

    数据视频先看坐标轴从哪开始、总数是多少、比较的是不是同一群人。

  11. 影像史与素养 / 媒介素养

    赞助披露：广告要让人看见

    赞助披露要在观众看到推荐之前出现，不要藏在简介最后一行。

  12. 影像史与素养 / 媒介素养

    新闻视频：现场、二手信源与核实

    新闻视频先分现场、二手信源和核实；没有核实的“现场”只是素材。

  13. 业务 / 法律深页

    肖像、场地与未成年人授权：一张 Release 要写什么

    拍摄同意不等于商用同意。肖像权、场地物权、未成年人监护人同意、AI 换脸/合成，是四份不同的授权；一张“同意拍摄”纸条救不了广告投放。

  14. 影像史与素养 / 法律与伦理

    隐私与打码：什么时候必须处理

    打码不是礼貌，是义务：住址、车牌、病历、未成年人，能识别就要处理。

  15. 业务 / 法律深页

    合同范围：把“再改一版”写进价格之前

    影视合同最常见的争议不是付款，是范围。交付物、修改轮次、素材版权、验收标准、终止条件没写清，最后都会变成免费加班。

  16. 业务 / 法律深页

    音乐授权：同步权、表演权与平台曲库

    “买了这首歌”不等于“能商用”。影视项目至少要区分同步权（把歌录进片子）、表演权（公开播放）、机械复制权（复制音频）和录音制作者权。

  17. 影像史与素养 / 法律与伦理

    场地许可：纸要写什么

    场地许可写清拍摄时间、区域、干扰、损坏责任和成片使用权。

  18. 业务 / 法律深页

    AI 内容标识：显式、隐式与平台责任

    AI 生成内容不是“标注一下”就合规。中国大陆的标识规则区分显式标识与隐式标识，平台、工具提供者、发布者各有义务；广告与新闻场景更严。

  19. 影像史与素养 / 法律与伦理

    纪录片伦理：拍脆弱的人

    拍脆弱的人先问三件事：他知不知道后果、能不能退出、片子会不会伤害他。

  20. 影像史与素养 / 法律与伦理

    素材安全：客户隐私与泄露

    素材安全包括硬盘、云盘、聊天记录和转发权限；客户隐私不是只有正片。
