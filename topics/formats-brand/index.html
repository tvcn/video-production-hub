广告与品牌

产品广告、品牌片、企业宣传：三秒问题、十秒证明，最后落回一句可相信的话。

10 篇 · 按主题聚合，不按发布时间

  1. 片型 / 产品广告

    产品广告：三秒抓人，十秒讲清

    产品广告不是产品展示片。前三秒给问题，中段给一个卖点，结尾给一个动作。

  2. 片型 / 品牌片

    品牌片：先让人相信一句话

    品牌片不解释参数，它让观众记住一个态度。产品只是证据，不是主角。

  3. 片型 / 产品广告

    产品广告拉片：问题怎么变成证据

    按 60 秒产品广告的通用结构，拆 9 个时间码：问题、失败、产品、演示、证据、异议、第二证据、结果、行动。

  4. 片型 / 产品广告

    产品广告模板：三秒问题、十秒证明

    产品广告模板前三秒给问题，十秒给证明，最后五秒给一个动作。

  5. 片型 / 品牌片

    品牌片拉片：90 秒怎么建立世界

    按 90 秒品牌片的通用结构，拆 9 个时间码：世界、人物、欲望、阻碍、转向、行动、落点、一句话、停留。

  6. 片型 / 品牌片

    品牌片模板：主张、证据、落点

    品牌片模板立场、证据、落点；立场要能被反对，证据要具体。

  7. 片型 / 企业宣传

    企业宣传结构：六个拍点

    企业宣传不是公司简介视频。先写一个观众愿意看完的问题，再用一个人、一个动作证明公司解决了它。

  8. 片型 / 拉片 / 企业宣传

    企业宣传拉片：六个段落怎么落地

    综合样例：把企业宣传拆成六拍，逐段看画面、声音和通过线；示例数字只作示范，不是客户数据。

  9. 片型 / 模板 / 企业宣传

    企业宣传模板：一张表拍完

    企业宣传一张表：六拍、画面、声音、时长与通过线；开机前填完，现场只认这张表。

  10. 片型 / 深读

    品牌片：模板、拆解、企业结构

    品牌片不是企业简介；一个卖点、一个人物和一个可记住的动作比十个部门更重要。
