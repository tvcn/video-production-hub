纪录与活动

纪录、访谈、活动与婚礼：先保现场，再谈风格；先让人物成立，再让流程好看。

20 篇 · 按主题聚合，不按发布时间

  1. 片型 / 纪录

    纪录短片：拍到一个变化

    先找到一个人，再等一件事发生。片子成立，往往是因为开机前后他变了点什么。

  2. 片型 / 婚礼

    婚礼片结构：先保仪式，再谈风格

    婚礼片先保仪式和誓言，再谈慢动作和调色；仪式没拍到，风格救不回来。

  3. 片型 / 纪录

    纪录短片拉片：一个人、一件事、一个变化

    按 3 分钟纪录短片的通用结构，拆 8 个时间码：动作、人物、欲望、阻碍、尝试、代价、变化、之后。

  4. 片型 / 纪录

    纪录模板：一个人、一件事、一个变化

    纪录模板一个人、一件具体的事、一个能看见的变化；不要从时代开始讲。

  5. 片型 / 新闻

    新闻结构：先给现场，再给核实

    新闻结构先给现场，再给核实；先讲背景，观众已经走了。

  6. 片型 / 新闻

    新闻拉片：90 秒怎么把未知留在片里

    按 90 秒新闻短片的通用结构，拆 8 个时间码：已核实事实、现场、目击者、资料、背景、已知/未知、未解、下一步。

  7. 片型 / 新闻

    新闻模板：现场、背景、影响

    新闻模板现场、背景、影响；每一段都要回答一个观众的问题。

  8. 片型 / 婚礼

    婚礼拉片：6 分钟怎么不拍成流程

    按 6 分钟婚礼片的通用结构，拆 11 个时间码：准备、到场、仪式、誓言、戒指、家人、宴会、舞会、安静、肖像、离开。

  9. 片型 / 婚礼

    婚礼模板：开场、仪式、祝福

    婚礼模板开场、仪式、祝福；开场给一天的感觉，不是给婚纱特写。

  10. 片型 / 活动

    活动片结构：先给结果，再给过程

    活动片先给结果，再给过程；观众要知道这场活动成了什么。

  11. 片型 / 活动

    活动片拉片：90 秒怎么讲清现场

    按 90 秒活动片的通用结构，拆 8 个时间码：到场、规模、关键瞬间、细节、人、高潮、之后、落版。

  12. 片型 / 活动

    活动片模板：开场、现场、收束

    活动片模板开场、现场、收束；现场段落要有环境声，不要全铺音乐。

  13. 片型 / 访谈

    访谈结构：问题比机位重要

    访谈结构里问题比机位重要；问题太空，回答只能空。

  14. 片型 / 访谈

    采访拉片：3 分钟怎么让人物成立

    按 3 分钟采访片的通用结构，拆 9 个时间码：答案钩子、人物在工作、问题一、证据、问题二、转向、语境、收束、停留。

  15. 片型 / 访谈

    访谈模板：人物、问题、场景

    访谈模板人物、问题、场景；先拍他能做事的地方，再坐下来讲。

  16. 片型 / 模板 / 企业宣传

    企业宣传模板：一张表拍完

    企业宣传一张表：六拍、画面、声音、时长与通过线；开机前填完，现场只认这张表。
