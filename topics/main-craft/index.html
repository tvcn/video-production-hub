手艺与判断

从定义问题到验收交付：先判断这片子要解决什么，再选方法，最后用可检查的结果收尾。

20 篇 · 按主题聚合，不按发布时间

  1. 主站 / 学习路径

    剪辑、调色与声音

    从素材整理到交付，走一遍可复用的后期流程：先结构，再声音，最后调色，交付前做一次技术检查。

  2. 主站 / 学习路径

    媒介素养

    用一套固定顺序判断一条视频：来源、剪辑、语境、钱、AI 痕迹、图表、权利。先停三秒，再下结论。

  3. 主站 / 方法卡

    只有一个模糊想法

    模糊想法先别写剧本，先写三句“谁想要什么、被什么挡住、输了会怎样”。

  4. 主站 / 方法卡

    不会写剧本

    不会写剧本就先写八格分镜，每格只写一个动作；动作会逼出对白。

  5. 主站 / 方法卡

    找不到演员

    找不到演员就先拍手、背影、物件和声音；不露脸也能讲一个完整的人。

  6. 主站 / 方法卡

    只有一个房间

    一个房间也能拍，只要让空间在片子进行中改变一次：变乱、变空、变暗。

  7. 主站 / 方法卡

    没有灯怎么拍

    没有灯先用窗、白墙、反光板和手机手电；先找方向，再谈亮度。

  8. 主站 / 方法卡

    预算为零

    零预算先砍场面，不砍结构；一个能拍完的简单故事，比一个拍不起的好故事强。

  9. 主站 / 方法卡

    一个人怎么拍

    一个人拍先用固定机位和连续动作；不要同时演、拍、跟焦。

  10. 主站 / 方法卡

    只有手机

    手机拍片先锁曝光和白平衡，再配一个能固定的东西；稳定和收音比镜头重要。

  11. 主站 / 方法卡

    画面很平

    画面平通常不是机器问题，是光没有方向、前后景没有分开。

  12. 主站 / 方法卡

    暗部很脏

    暗部脏先降 ISO、补一点环境光、别硬拉暗部；拉回来的黑是噪点。

  13. 主站 / 方法卡

    高光爆了

    高光爆了先降一档、换 ND、关掉不必要的 practical；爆掉的像素救不回来。

  14. 主站 / 方法卡

    颜色偏了

    颜色偏先找白平衡和混合光，不要一上来调色轮；源头不对，越调越脏。

  15. 主站 / 方法卡

    底噪很大

    底噪大先查房间、空调、线和增益；麦克风最后再换。

  16. 主站 / 方法卡

    外景风噪

    外景风噪先给麦克风套防风罩，再找背风处；后期降噪救不回被风吞掉的字。

  17. 主站 / 方法卡

    演员很僵

    演员僵先给一个具体任务，再让他走一步；身体动起来，台词才会松。

  18. 主站 / 方法卡

    台词像念稿

    台词像念稿先删解释、加动作、让演员看着一个人说；不要加更多形容词。

  19. 主站 / 方法卡

    一场戏没变化

    一场戏没变化，就删掉它，或者让一个人得到/失去一样东西。

  20. 主站 / 方法卡

    开头太慢

    开头慢先删前三十秒，从人物已经在做事的地方开始；背景可以后补。
