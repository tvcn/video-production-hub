声音后期与字幕

降噪、混音、字幕与交付：先修可修的，再谈氛围；字幕是读的，不是抄的。

20 篇 · 按主题聚合，不按发布时间

  1. 后期 / 剪辑

    粗剪：先让片子成立

    粗剪只做一件事：让陌生人看懂谁想要什么、被什么挡住。节奏、调色、配乐都往后放。

  2. 后期 / 声音

    声音：先对白，再音乐

    观众可以忍受画面粗糙，但很难忍受听不清。先把对白做干净，再谈音乐和氛围。

  3. 后期 / 调色

    调色：先统一，再风格

    调色先解决白平衡、曝光和镜头匹配，再谈 LUT 和风格。镜头之间不连，风格越多越乱。

  4. 后期 / 节奏

    节奏不是快，是观众什么时候想听下一句

    剪得快不等于好看。先删解释，再把切点放在动作上，最后决定哪里该留安静。

  5. 后期 / 声音

    声音后期先修噪声，再谈氛围

    一条片子的声音不舒服，观众不会说“声音不好”，只会说“看不下去”。先处理底噪、电平、同步，再考虑音乐。

  6. 后期 / 合成

    合成：先让两层信同一种光

    抠得像不等于合得成。边缘之前，先对光的方向、软硬、色温和接触阴影。

  7. 后期 / 剪辑

    声音先走：J-cut 与 L-cut

    画面切了，声音不必同时切。让下一场的声音先进来，或让上一场的声音留一会儿，硬切就不会撞观众一下。

  8. 后期 / 字幕

    字幕：让观众读完，不是逐字抄

    字幕不是台词的复制件。它要在观众还来不及读的时候，把意思送进去：一行别太长，一句话别断在错的地方，数字和名字要能一眼认出来。

  9. 后期 / 剪辑

    剪辑点：让注意力过去

    剪不动，不一定素材不够，是切点没选对。一个镜头结束，观众的眼睛、耳朵或动作得有一个着落；三样都没有，切口就会跳。

  10. 后期 / 声音

    混音：先让对白站住，再加音乐

    观众可以不听音乐，但不能听不清台词。先把对白压到同一水平，再把音乐推下去；音乐是背景，不是遮羞布。

  11. 后期 / 声音

    环境音：别让画面住在真空里

    房间的声音不是噪声，是空间。每换一个地方，录三十秒空场；没有人声、没有动作，只有房间。对白一断，环境音接上，观众才不会觉得画面被剪断。

  12. 后期 / 剪辑

    转场：不是遮住时间，是交代时间

    叠化、黑场、划像不是装饰。每一次转场都在回答：过了多久、去了哪里、谁还在。答不清，就硬切。

  13. 后期 / 片头字

    片头字：先读清，再谈酷

    片头字先保证读得清，再谈风格；观众连片名都没看清，设计就白做了。

  14. 后期 / 剪辑

    代理流程：先能剪，再谈画质

    代理不是降低成片质量，是让剪辑先跑起来；原始素材永远留在旁边。

  15. 后期 / 调色

    一级校正：曝光与白平衡

    一级校正先解决曝光和白平衡，别用风格掩盖技术问题。

  16. 后期 / 录音

    响度：平台目标与真峰值

    响度按平台目标交付，真峰值留余量；声音大不等于声音好。

  17. 后期 / 剪辑

    细剪：把粗剪的毛边修掉

    细剪不是加特效，是把每个切换、每句呼吸、每个多余半秒修顺。

  18. 后期 / 剪辑

    平行剪辑：两条线什么时候交叉

    平行剪辑不是来回切，它要让两条线在观众心里产生一个问题：什么时候撞上。

  19. 后期 / 剪辑

    版本管理：别用“final 真的 final”

    版本管理用日期、平台、时长和改动原因命名，别用“final 真的 final”。

  20. 后期 / 色彩管理

    色彩管理：把 LUT 放在正确的位置

    色彩管理不是套一个“电影感 LUT”。它先回答：素材是什么色彩空间、监视器是什么、交付是什么；再把转换放在正确的节点上。
