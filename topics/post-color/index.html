调色与合成

先统一，再风格；合成先让两层信同一种光，再谈特效。

13 篇 · 按主题聚合，不按发布时间

  1. 后期 / 剪辑

    粗剪：先让片子成立

    粗剪只做一件事：让陌生人看懂谁想要什么、被什么挡住。节奏、调色、配乐都往后放。

  2. 后期 / 调色

    调色：先统一，再风格

    调色先解决白平衡、曝光和镜头匹配，再谈 LUT 和风格。镜头之间不连，风格越多越乱。

  3. 后期 / 合成

    合成：先让两层信同一种光

    抠得像不等于合得成。边缘之前，先对光的方向、软硬、色温和接触阴影。

  4. 后期 / 调色

    一级校正：曝光与白平衡

    一级校正先解决曝光和白平衡，别用风格掩盖技术问题。

  5. 后期 / 色彩管理

    色彩管理：把 LUT 放在正确的位置

    色彩管理不是套一个“电影感 LUT”。它先回答：素材是什么色彩空间、监视器是什么、交付是什么；再把转换放在正确的节点上。

  6. 后期 / 调色

    二级校正：只改一块颜色

    二级校正只改一个区域：脸、天空、衣服；改得越多，越容易假。

  7. 后期 / 调色

    LUT：起点不是终点

    LUT 是起点，不是终点；套完之后还要回到一级校正看黑位和高光。

  8. 后期 / 调色

    HDR：先有 HDR 的素材和监看

    HDR 不是把 SDR 拉亮；拍摄、监看、交付都得真的支持 HDR。

  9. 后期 / 调色

    示波器：黑位、白位、肤色

    示波器先看三件事：黑位有没有死、白位有没有爆、肤色线偏没偏。

  10. 后期 / 特效

    抠像：先抠边缘，再调色

    抠像先看边缘，再看颜色；边缘糊了，调色救不回来。

  11. 后期 / 特效

    CG 合成：光、影、雾一起对

    CG 合成先对光的方向、影子的软硬、空气的雾，再谈细节。

  12. 后期 / HDR

    HDR 全流程：从监看到交付，不要只在最后加亮

    HDR 不是把 SDR 拉亮，而是从拍摄、监看、调色到平台交付都保留同一套亮度关系。任何一个环节按 SDR 猜，最后都会得到“亮但平”的画面。

  13. 后期 / 归档与复用

    归档与资产复用：让下一条片子更快

    归档不是把文件夹拖进硬盘。它要让下一个人能打开工程、找到素材、知道授权、恢复调色和声音；复用不是翻旧片，是有索引地取用。
