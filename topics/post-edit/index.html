剪辑与节奏

剪辑点、节奏、J-cut 与 L-cut：让观众在下一句之前就想听。

12 篇 · 按主题聚合，不按发布时间

  1. 后期 / 剪辑

    粗剪：先让片子成立

    粗剪只做一件事：让陌生人看懂谁想要什么、被什么挡住。节奏、调色、配乐都往后放。

  2. 后期 / 节奏

    节奏不是快，是观众什么时候想听下一句

    剪得快不等于好看。先删解释，再把切点放在动作上，最后决定哪里该留安静。

  3. 后期 / 剪辑

    声音先走：J-cut 与 L-cut

    画面切了，声音不必同时切。让下一场的声音先进来，或让上一场的声音留一会儿，硬切就不会撞观众一下。

  4. 后期 / 剪辑

    剪辑点：让注意力过去

    剪不动，不一定素材不够，是切点没选对。一个镜头结束，观众的眼睛、耳朵或动作得有一个着落；三样都没有，切口就会跳。

  5. 后期 / 剪辑

    转场：不是遮住时间，是交代时间

    叠化、黑场、划像不是装饰。每一次转场都在回答：过了多久、去了哪里、谁还在。答不清，就硬切。

  6. 后期 / 剪辑

    代理流程：先能剪，再谈画质

    代理不是降低成片质量，是让剪辑先跑起来；原始素材永远留在旁边。

  7. 后期 / 剪辑

    细剪：把粗剪的毛边修掉

    细剪不是加特效，是把每个切换、每句呼吸、每个多余半秒修顺。

  8. 后期 / 剪辑

    平行剪辑：两条线什么时候交叉

    平行剪辑不是来回切，它要让两条线在观众心里产生一个问题：什么时候撞上。

  9. 后期 / 剪辑

    版本管理：别用“final 真的 final”

    版本管理用日期、平台、时长和改动原因命名，别用“final 真的 final”。

  10. 后期 / 录音

    配乐剪辑：让音乐跟着动作

    配乐不是从头铺到尾，它要在动作转折处进入、退出、留白。

  11. 后期 / 素材

    代理与缓存：别让硬盘先满

    代理和缓存要放在独立盘，别让剪辑盘先满；满了就会掉帧。

  12. 后期 / Conform

    Conform / Online：套底、回批与母版

    Conform 不是把剪辑时间线换个软件打开。它要确认每一刀都回到原始素材、每一段都有足够 handles、每一个版本都能回到同一条母版。
