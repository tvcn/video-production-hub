曝光与构图

判断：曝光、构图、机位与运镜：先保证每条都能剪，再谈镜头风格。

18 篇 · 按问题顺序，不按发布时间

先读这五篇

  1. 先读：定问题曝光三角：先把高光保住

    快门、光圈、ISO 不是三个平等旋钮。先定运动，再定景深，最后才用 ISO 救场。

  2. 再读：选动作构图：先让观众知道看哪里

    观众第一眼该看谁，第二眼该看哪，构图就是排这个顺序。先定主体，再管前中后景。

  3. 补读：看失败越轴之后，观众会突然找不到方向

    两个人对话，摄影机跨到桌子另一边，观众会以为他们换了位置。先定一条线，再决定要不要跨。

  4. 验读：做验收运镜：先问为什么动，再问怎么动

    镜头动起来不难，难的是让观众不觉得摄影机在炫耀。动之前先写清楚：观众要跟着谁、发现什么、被什么压住。

  5. 横读：补一课机位高度：蹲下比换镜头有用

    同一张脸，机位高一寸，观众就读成另一个人。高度先决定权力关系，再决定景别；换镜头解决不了站错位置。

为什么这样排：先判断问题，再选动作，接着补失败与验收，最后横向补一课；不是按发布时间，也不是按文章数量。下面 8 篇以上是完整子页清单。

  1. 拍摄 / 曝光

    曝光三角：先把高光保住

    快门、光圈、ISO 不是三个平等旋钮。先定运动，再定景深，最后才用 ISO 救场。

  2. 拍摄 / 构图

    构图：先让观众知道看哪里

    观众第一眼该看谁，第二眼该看哪，构图就是排这个顺序。先定主体，再管前中后景。

  3. 拍摄 / 机位

    越轴之后，观众会突然找不到方向

    两个人对话，摄影机跨到桌子另一边，观众会以为他们换了位置。先定一条线，再决定要不要跨。

  4. 拍摄 / 运镜

    运镜：先问为什么动，再问怎么动

    镜头动起来不难，难的是让观众不觉得摄影机在炫耀。动之前先写清楚：观众要跟着谁、发现什么、被什么压住。

  5. 拍摄 / 机位

    机位高度：蹲下比换镜头有用

    同一张脸，机位高一寸，观众就读成另一个人。高度先决定权力关系，再决定景别；换镜头解决不了站错位置。

  6. 拍摄 / 镜头

    焦距：先决定观众站多远

    广角不是装得下，长焦不是拍得远。焦距先决定观众离人物多远，再决定脸和背景怎么挤。先走位，再换镜头。

  7. 拍摄 / 景别

    景别：观众该看见多少

    景别不是远景、中景、特写的名词表。它决定观众和人物的距离：看见他站在哪，还是只看见一个眼神。先问这一刀要观众看什么，再决定机位退到哪儿。

  8. 拍摄 / 机身

    传感器尺寸：画幅决定什么

    传感器尺寸改变的是视角、景深和低光，不是“电影感”本身。

  9. 拍摄 / 曝光

    波形图：看曝光，不靠感觉

    波形图看亮度分布，不看画面好不好看；先保高光，再决定暗部留多少。

  10. 拍摄 / 曝光

    伪色：一眼看高光

    伪色把亮度分成色块，一眼就能看到脸是不是过曝、天空是不是死了。

  11. 拍摄 / 曝光

    Log 素材：拍的时候想后期

    Log 不是“灰片更好看”，它把高光和暗部留给后期，前提是曝光和色彩管理做对。

  12. 拍摄 / 灯光

    硬光：影子也是构图

    硬光不是“难看”，它用影子划分空间；问题通常出在影子落错地方。

  13. 拍摄 / 多机位

    多机位同步：时间码与机位图

    多机位先画机位图，再对时间码；剪辑要知道哪台机器站在哪。

  14. 拍摄 / 多机位与直播

    多机位与直播：先把时间码、返送和录制锁死

    多机位不是多摆两台机器，而是让三台机器进同一条时间线、同一套返送、同一份录音。任何一个环节没有备份，现场就会从“导播”变成“猜”。

  15. 拍摄 / 深读

    运镜：手持、稳定器、覆盖

    运镜不是让画面动起来，而是让运动服务走位、覆盖和剪辑点。

  16. 拍摄 / 深读

    多机位：同步、覆盖、走位

    多机位不是多开几台机器；同步、景别分工和走位重复，缺一个就剪不起来。

  17. 拍摄 / 深读

    Log 与曝光：波形、假色、ND

    Log 不是万能；曝光、ND 和假色要一起定，否则后期只剩一张灰片。

  18. 拍摄 / 曝光

    低照度拍摄：噪点、快门与实用光

    夜景不是把 ISO 拉高，而是先决定哪些黑可以接受，再用实用光和快门换回细节。
