灯光

一扇窗、一盏灯、一块反光板：先有方向，再谈氛围；先保肤色，再谈造型。

8 篇 · 按主题聚合，不按发布时间

  1. 拍摄 / 灯光

    灯比：先学 ratio，再学灯位

    一盏主灯加一块反光板，已经能拍出大部分人物场景。先控制亮暗差，再追求灯位花样。

  2. 拍摄 / 自然光

    一扇窗怎么当主光

    没有灯组也能拍人脸：先定朝向，再用反光板补一点，最后把背景压下去。

  3. 拍摄 / 灯光

    灯光风格：柔、硬、自然

    灯光风格先选一个方向：柔、硬、自然；三个都要，画面就会没有态度。

  4. 拍摄 / 灯光

    夜景内景：一盏 practical 怎么撑

    夜景内景先找画面里能信的实用光，再用一盏小灯补人脸，别把整间房打平。

  5. 拍摄 / 灯光

    混合光：两种色温别打平

    混合光不要全部打成白；保留窗光冷、灯泡暖，空间才有层次。

  6. 拍摄 / 灯光

    硬光：影子也是构图

    硬光不是“难看”，它用影子划分空间；问题通常出在影子落错地方。

  7. 拍摄 / 灯光

    实用光：画面里的灯怎么用

    画面里的灯要真的亮、真的灭、真的闪，但它照不亮整张脸，只能当动机。

  8. 拍摄 / LED 虚拟拍摄

    LED 虚拟拍摄：墙、跟踪、同步与色温

    LED 虚拟拍摄不是“背景换成屏幕”。它把真实光影、相机跟踪、屏幕刷新和后期色彩绑成一条链；任何一项没锁，演员脸上的光就会和背景分开。
