结构与分镜

开场、场景、转折、节奏与分镜：观众先知道跟谁走，镜头才知道该看什么。

20 篇 · 按主题聚合，不按发布时间

  1. 故事 / 编剧

    一句话故事：谁想要什么，被什么挡住

    把模糊的想法压成一句能拍的话：一个具体的人，想要一个具体的东西，被一个具体的障碍挡住。

  2. 故事 / 分镜

    分镜表：把一句话拆成 8 个能拍的镜头

    画得丑没关系，现场看得懂就行。一张分镜表只回答三件事：谁、在哪、下一个动作是什么。

  3. 故事 / 结构

    三幕片的骨架：把人物往墙上逼

    第一幕给目标，第二幕加阻力，第三幕让选择发生。每一幕只做一件事。

  4. 故事 / 采访

    采访别问“你有什么感受”：把问题换成动作

    一个人回忆不起“感受”，但记得那天先迈了哪只脚。问题越具体，回答越像人话。

  5. 故事 / 对白

    对白：让人物用嘴争，不用嘴解释

    对白写不动，常常是因为把人物想说的话都写了出来。好对白每句都在争一个东西，听的人有反应，背景交给画面。

  6. 故事 / 冲突

    冲突：两个人都得有道理

    吵架不等于冲突。真正的冲突，是两个人要的东西都合理，但只能有一个结果。观众得同时看懂两边，才会替他们难受。

  7. 故事 / 人物

    人物弧光：不是变好，是选择变了

    弧光不是人物从坏变好。是同一个压力下，他第一次选了安全，最后一次选了代价。观众看到的是选择变了，不是性格标签换了。

  8. 故事 / 旁白

    旁白：别替观众总结

    旁白不是把画面再说一遍。它要么给画面没有的信息，要么给一个人的判断。能拍出来就别念；要念，就短、具体、带偏见。

  9. 故事与编剧 / 故事

    欲望与赌注：输了会失去什么

    人物想要什么不重要，重要的是得不到会失去什么。

  10. 故事与编剧 / 编剧

    场景描述：只写镜头拍得到的

    场景描述只写镜头拍得到的东西：光、动作、物件、声音；心理活动留给演员。

  11. 故事与编剧 / 分镜

    镜头表：镜号、景别、动作、时长

    镜头表四列就够：镜号、景别、动作、时长；写不清这四样，现场一定乱。

  12. 故事与编剧 / 导演

    排练：先走位，再给台词

    排练先走位，台词可以拿在手上；身体站对了，话才有地方落。

  13. 故事与编剧 / 故事

    障碍升级：同一堵墙越收越紧

    同一个障碍连撞三次，每次代价更高，观众才会觉得人物真的被逼到墙角。

  14. 故事与编剧 / 故事

    中点转向：换方法，不换目标

    中点不是反转剧情，而是人物换一种办法去要同一个东西。

  15. 故事与编剧 / 故事

    场景序列：三场戏推一个变化

    一场戏只完成一个变化，三场戏连起来才推得动一个段落。

  16. 故事与编剧 / 故事

    支线：只留能压主线的一条

    支线不是增加热闹，它要在某个时刻把主线逼得更紧。

  17. 故事与编剧 / 故事

    主题：让人物做出来，不让他说出来

    主题不要让人物讲出来，让他在压力下做一个能暴露价值观的选择。

  18. 故事与编剧 / 故事

    结尾：停在选择之后

    结尾停在选择之后，别再加一段解释；观众自己补上的那句更有力。

  19. 故事与编剧 / 故事

    短片经济：删掉拍不起的东西

    短片先删掉拍不起的场面，再把剩下的东西写得更具体。

  20. 故事与编剧 / 编剧

    剧本格式：让全组读得懂

    剧本格式不是给文学奖看的，它要让摄影、录音和剪辑一眼找到信息。
