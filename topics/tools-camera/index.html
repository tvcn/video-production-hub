机身与镜头

机身、镜头、取景与稳定：先问拍什么，再问买什么；参数不等于画面。

20 篇 · 按主题聚合，不按发布时间

  1. 工具 / 机身

    相机怎么选：先看约束，不看品牌

    先写你拍什么、在哪拍、给谁看、能背多重，再选机身。参数表不能替你做决定。

  2. 工具 / 计算器

    存储时长计算器：卡能录多久

    存储计算器按码率、时长和备份份数算空间；卡能录多久，不要靠相机剩余时间。

  3. 工具 / 能力卡

    定焦镜头：先走动，再变焦

    定焦不是不能变焦，它逼你走近、退后、换机位；这通常比拧变焦环更有用。

  4. 工具 / 能力卡

    变焦镜头：方便与画质

    变焦镜头省时间，但要在重量、光圈和画质之间付账；先问今天最缺哪一样。

  5. 工具 / 能力卡

    增光减焦：画幅与光圈

    增光减焦把全画幅镜头压到小画幅机身上，视角变宽、光圈约快一档，但边缘可能变软。

  6. 工具 / 能力卡

    跟焦器：单手能跟

    跟焦器让焦点变化有刻度、有手感；自动对焦在暗处和快速运动时不一定靠得住。

  7. 工具 / 能力卡

    三脚架：云台与承重

    三脚架先看承重和云台，不看最大高度；相机加镜头加配件，往往比标称重。

  8. 工具 / 能力卡

    AI 视频工具：先看可控性

    AI 视频工具先看可控性：能不能锁角色、锁镜头、锁时长；只看样片会被骗。

  9. 工具 / 教程

    相机黑平衡：别把噪点当风格

    相机黑平衡按机器要求做，别把噪点当风格；暗部干净，后期才有空间。

  10. 工具 / 教程

    滑轨起停：让运动有头尾

    滑轨镜头要有头、身、尾：起幅停半秒、过程匀、落幅停半秒。

  11. 工具 / 购买指南

    购买相机：先定预算，再定机身

    预算有限时，机身不是第一优先级。先确认你缺的是暗光、自动对焦、10-bit、还是收音；买错机身，后面每一件配件都要跟着换。

  12. 工具 / 选购与排障

    租相机：保险、押金、检查

    租相机先买保险、交押金、当面检查；划痕和坏点拍视频留证。

  13. 工具 / 购买指南

    先买镜头：焦段、光圈与呼吸

    镜头决定画面的一半，而且比机身保值。先买一支能覆盖 70% 场景的焦段，再买第二支；不要一开始凑三支便宜变焦。

  14. 工具 / 购买指南

    先买录音：麦克风、底噪与增益

    观众能忍画面普通，忍不了声音听不清。预算有限时，先把钱放在麦克风和录音机，而不是第二支镜头。

  15. 工具 / 购买指南

    购买监视器：亮度、色域与延迟

    监视器不是“外接大屏”。现场要亮到看得见、色彩要能校准、延迟要能对焦；三项任何一项不够，都还不如机头屏。

  16. 工具 / 选购与排障

    相机过热：降温与分段拍

    相机过热先降温、分段拍、降码率；不要用湿毛巾直接敷机身。

  17. 工具 / 选购与排障

    果冻效应：读速与快门

    果冻效应来自慢读出和快速运动；先换机器，再调快门，别只怪镜头。

  18. 工具 / 购买指南

    购买电影机：别把“能拍”当成“能交”

    电影机的价格不只在机身：卡、电池、监看、底座、提手、线材、调色和学习都要算。先确认项目真的需要 RAW、时码、SDI 和双卡，否则一台高端视频机更划算。

  19. 工具 / 购买指南

    购买存储卡：VPG、持续写入与发热

    卡的标称读取速度没有意义，持续写入才决定会不会丢帧。先看相机要求的最小持续写入，再买高一档的卡，并至少两张轮换。

  20. 工具 / 购买指南

    第一台稳定器：承重、调平与跟随

    稳定器不是“走路不抖”的魔法。承重余量、三轴调平、跟随手感、电池和轴锁，决定你能不能用它拍完一个镜头。
