灯光与录音

LED、柔光、无线麦与录音机：先解决方向与距离，再谈功率与品牌。

20 篇 · 按主题聚合，不按发布时间

  1. 工具 / 录音

    录音入门：话筒位置比设备贵更重要

    同一支便宜话筒，放在离嘴 20 厘米的位置，通常比一万元设备放在机顶更好。

  2. 工具 / 能力卡

    LED 面板灯：显色与亮度

    LED 面板灯先看显色指数和实际亮度，不看包装上的瓦数；人脸发绿就是显色不对。

  3. 工具 / 能力卡

    COB 灯：一盏灯加柔光箱

    COB 灯是裸光源，必须配柔光箱或灯笼；裸着照人脸，影子会硬得没法看。

  4. 工具 / 能力卡

    柔光箱：尺寸决定柔度

    柔光箱越大、越近，光越柔；换灯不如先把柔光箱靠近人物。

  5. 工具 / 能力卡

    灯光色纸：CTO、CTB、ND

    灯光色纸先分清 CTO、CTB、ND：一个加暖、一个加冷、一个减亮；贴错会改掉整个现场。

  6. 工具 / 能力卡

    实用灯泡：色温与调光

    实用灯泡要能调色温和亮度，否则画面里的灯只能当道具，不能当光源。

  7. 工具 / 能力卡

    灯架与沙袋：安全第一

    灯架先放沙袋，再升灯；一根没配重的灯架，倒下来比灯贵。

  8. 工具 / 能力卡

    无线领夹系统：频段与备份

    无线领夹先查频段和干扰，再录一条备用轨；现场没有第二次机会。

  9. 工具 / 能力卡

    录音机：32-bit 浮点

    32-bit 浮点录音能救回削波，但救不回被风吞掉的对白；麦克风和位置还是第一位。

  10. 工具 / 能力卡

    时间码：多机同步

    时间码让多机位和录音机在后期的第一分钟就对上；没有它，合板要靠运气。

  11. 工具 / 能力卡

    音频接口：输入与增益

    音频接口先看输入数量、增益范围和底噪；接口再贵，增益不够也录不了小声。

  12. 工具 / 能力卡

    无线图传：延迟与干扰

    无线图传先测延迟和干扰，再决定给导演还是给跟焦；信号断了，现场就会停。

  13. 工具 / 能力卡

    AI 音频工具：授权与音质

    AI 音频工具先查授权和音质，再看功能；克隆声音的授权范围比音色重要。

  14. 工具 / 教程

    单灯人像：先有方向

    单灯人像先定方向：45 度、侧光还是逆光；方向对了，再谈柔硬和亮度。

  15. 工具 / 教程

    夜景实用光：曝光平衡

    夜景实用光先让画面里的灯成立，再用小灯补人脸；两者亮度差太多，就会假。

  16. 工具 / 购买指南

    先买录音：麦克风、底噪与增益

    观众能忍画面普通，忍不了声音听不清。预算有限时，先把钱放在麦克风和录音机，而不是第二支镜头。

  17. 工具 / 购买指南

    购买灯光套装：先买柔，再买亮

    第一套灯不是最亮的，是最容易控制肤色和阴影的。柔光面积、色温一致、可调功率，比峰值亮度更重要。

  18. 工具 / 选购与排障

    灯光租赁：清单与损坏

    灯光租赁先列清单、试亮、拍损坏；少一个灯罩，现场就得多等一小时。

  19. 工具 / 选购与排障

    底噪排查：从房间开始

    底噪排查从房间开始：关空调、关灯、换插座、换线；最后才怪麦克风。

  20. 工具 / 购买指南

    现场录音机：通道、32 位浮点与时码

    现场录音机的核心不是“能录几轨”，而是“断了一个通道还有没有备份、增益错了能不能救、后期能不能对时码”。
