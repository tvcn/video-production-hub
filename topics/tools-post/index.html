导出与软件

编码、导出、软件与交付：先问平台和用途，再选参数；先能重做，再谈一键。

16 篇 · 按主题聚合，不按发布时间

  1. 交付 / 发布

    发布前 12 项检查：别在最后一小时翻车

    授权、技术、发布三组检查。每一项都能在十分钟内查完，别等到上传后才看到黑帧和错字。

  2. 工具 / 交付

    交付：别在最后导错文件

    交付不是点导出。先问平台要什么：比例、分辨率、帧率、码率、色彩、声道、文件名。做一个能重复的模板，交付前自己从头播一遍。

  3. 工具 / 能力卡

    电影机：传感器、卡口、录制

    电影机先看传感器、卡口和录制格式；名字和外形不决定它能不能拍你的项目。

  4. 工具 / 能力卡

    剪辑软件怎么选：项目先定

    剪辑软件按项目选：团队协作、代理、调色、字幕、交付，各有所长；别按教程数量选。

  5. 工具 / 能力卡

    动画软件：2D、3D、定格

    动画软件按工序选：2D 看绘图和合成，3D 看绑定和渲染，定格看拍摄控制；一个软件不可能全包。

  6. 工具 / 教程

    代理生成：剪辑不卡

    代理按时间线和交付分辨率生成，别用完整分辨率硬剪；代理不对，字幕和构图会错。

  7. 工具 / 教程

    SRT 字幕：编码、时间轴、标点

    SRT 字幕先保 UTF-8 编码、时间轴和标点；编码错了，平台会显示乱码。

  8. 工具 / 教程

    H.264 导出：码率与兼容

    H.264 导出先定平台和码率，再选两遍编码；码率太低，运动画面先烂。

  9. 工具 / 教程

    ProRes 导出：归档与交付

    ProRes 用于归档和再调色，不是给所有平台直接上传；文件大，但能再改。

  10. 工具 / 计算器

    码率体积计算器：文件多大

    码率计算器按分钟和 Mbps 算文件体积；交付前先知道硬盘够不够。

  11. 工具 / 购买指南

    购买项目存储：速度、容量与备份

    存储不是“越大越好”，是“拍摄不断、拷回不丢、项目结束还能找得到”。先算一个项目日的真实数据量，再买盘。

  12. 工具 / 选购与排障

    导出失败排查：编码、磁盘、权限

    导出失败先查编码、磁盘空间、权限；三样都排除，再重建项目。

  13. 工具 / 剧组管理

    剧组管理：通告、签到、收工与责任

    剧组管理不是发通告，是让每个人知道今天做什么、出事找谁、什么时候能走。通告单、签到、收工报告三张纸决定项目是否可控。

  14. 工具 / 购买指南

    购买电影机：别把“能拍”当成“能交”

    电影机的价格不只在机身：卡、电池、监看、底座、提手、线材、调色和学习都要算。先确认项目真的需要 RAW、时码、SDI 和双卡，否则一台高端视频机更划算。

  15. 工具 / 购买指南

    购买电池：容量、通信与安全

    电池不是“能开机就行”。副厂电池可能不显示电量、突然掉电、胀包；拍一天项目，电池是安全件，不是省钱件。

  16. 工具 / 购买指南

    后期软件与交付：先定流程，再买工具

    剪辑、调色、声音、编码、审片是五个环节；先定流程，再决定订阅哪几个。不要一次买齐。
