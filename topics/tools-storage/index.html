存储与备份

卡、硬盘、NAS 与 3-2-1：先算容量与时长，再谈速度；先能恢复，再谈便宜。

20 篇 · 按主题聚合，不按发布时间

  1. 工具 / 素材

    素材管理：当天备份，命名可查

    拍摄结束前做完备份，文件名带日期、场次、机位。找不到的素材等于没拍。

  2. 工具 / 计算器

    存储时长计算器：卡能录多久

    存储计算器按码率、时长和备份份数算空间；卡能录多久，不要靠相机剩余时间。

  3. 工具 / 能力卡

    电影机：传感器、卡口、录制

    电影机先看传感器、卡口和录制格式；名字和外形不决定它能不能拍你的项目。

  4. 工具 / 能力卡

    微单拍视频：过热、果冻、裁切

    微单拍视频先查三件事：会不会过热、果冻有多明显、录视频时裁不裁画幅。

  5. 工具 / 能力卡

    定焦镜头：先走动，再变焦

    定焦不是不能变焦，它逼你走近、退后、换机位；这通常比拧变焦环更有用。

  6. 工具 / 能力卡

    变焦镜头：方便与画质

    变焦镜头省时间，但要在重量、光圈和画质之间付账；先问今天最缺哪一样。

  7. 工具 / 能力卡

    变形宽银幕：炫光与畸变

    变形宽银幕不是把画面上下裁掉；它压缩横向、再还原，所以有椭圆光斑和独特畸变。

  8. 工具 / 能力卡

    增光减焦：画幅与光圈

    增光减焦把全画幅镜头压到小画幅机身上，视角变宽、光圈约快一档，但边缘可能变软。

  9. 工具 / 能力卡

    遮光斗：滤镜与漏光

    遮光斗先挡杂光，再装滤镜；便宜的遮光斗可能漏光，反而毁画面。

  10. 工具 / 能力卡

    跟焦器：单手能跟

    跟焦器让焦点变化有刻度、有手感；自动对焦在暗处和快速运动时不一定靠得住。

  11. 工具 / 能力卡

    LED 面板灯：显色与亮度

    LED 面板灯先看显色指数和实际亮度，不看包装上的瓦数；人脸发绿就是显色不对。

  12. 工具 / 能力卡

    COB 灯：一盏灯加柔光箱

    COB 灯是裸光源，必须配柔光箱或灯笼；裸着照人脸，影子会硬得没法看。

  13. 工具 / 能力卡

    柔光箱：尺寸决定柔度

    柔光箱越大、越近，光越柔；换灯不如先把柔光箱靠近人物。

  14. 工具 / 能力卡

    反光板：五合一怎么用

    反光板五合一不是五种风格，是五种补光强度；先用白色，别一上来就银面。

  15. 工具 / 能力卡

    灯光色纸：CTO、CTB、ND

    灯光色纸先分清 CTO、CTB、ND：一个加暖、一个加冷、一个减亮；贴错会改掉整个现场。

  16. 工具 / 能力卡

    实用灯泡：色温与调光

    实用灯泡要能调色温和亮度，否则画面里的灯只能当道具，不能当光源。

  17. 工具 / 能力卡

    灯架与沙袋：安全第一

    灯架先放沙袋，再升灯；一根没配重的灯架，倒下来比灯贵。

  18. 工具 / 能力卡

    枪麦：指向性与离轴

    枪麦是指向性工具，离得远就只能收环境；先靠近，再谈降噪。

  19. 工具 / 能力卡

    无线领夹系统：频段与备份

    无线领夹先查频段和干扰，再录一条备用轨；现场没有第二次机会。

  20. 工具 / 能力卡

    录音机：32-bit 浮点

    32-bit 浮点录音能救回削波，但救不回被风吞掉的对白；麦克风和位置还是第一位。
